# Blaze & Blade – web remake (TypeScript / three.js)

Work-in-progress browser port of *Blaze & Blade: Eternal Quest* (T&E Soft, 1998). See `PROGRESS.md` for status
and `docs/FORMATS.md` for reverse-engineering notes.

```
npm install
npm run dev        # placeholder scene + sound-bank browser
npm run assets:snd # re-extract sounds from original/Snd
```
Original game files live in `original/` (private repo; do not publish).
